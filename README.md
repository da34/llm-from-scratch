# LLM from Scratch

## 项目简介

根据纳米 AI 的课程进行学习。

## 课程内容

### [lesson-01](lesson-01/)

**解决的问题**

从一问一答的聊天助手到真正能干活的 Agent。

**核心机制**

就是 loop，什么时候不需要调用工具就结束。

**为什么这样设计**

因为 LLM 的行为就非常适合 loop，没有工具调用证明已经结束了。

### [lesson-02](lesson-02/)

在 `lesson-01` 的基础上添加 `tool` 的实现。

### [lesson-03](lesson-03/)

**解决的问题**

工具在调用过程中不受控，LLM 可能会失控导致系统崩溃。

**核心机制**

添加 `tool` 的封装，新加工具不需要动主循环，并且加入工具的权限管控，危险命令需经过人的介入，并且限制工作区在启动目录。

对一些工具、命令进行白名单处理，比如读操作没有副作用就可以安全放心地执行；还有一些危险命令直接拒绝，比如 `rm`。

**为什么这样设计**

为了让 LLM 运行的过程更加可控，防止副作用。

### [lesson-04](lesson-04/)

**解决的问题**

在不断的循环当中，`messages` 会越来越大，而 LLM 的上下文窗口大小因模型而异，需要让持续循环中的上下文不超过模型的窗口限制。

**核心机制**

从便宜到贵，分为三层：

1. 工具结果入库前截断
2. 清理旧的工具结果
3. 使用 LLM 对早期的对话进行摘要

**为什么这样设计**

因为每一次对应的代价都是递增的，所以就按三层进行设计。

## 环境准备

Python 3.x

## 运行方式

创建虚拟环境：

```shell
python -m venv .venv
```

安装项目依赖：

```shell
python -m pip install -r requirements.txt
```

然后进入对应的课程目录，单文件启动：

```shell
python agent.py
```
